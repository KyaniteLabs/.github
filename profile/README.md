## What this org is

**Kyanite Labs** builds open-source **Model Context Protocol (MCP)** servers and domain tools that agents can call and humans can verify. Public work prioritizes local-first media, localization, estimation, creative coding, living websites, and ceramics software—with tested installs, concrete examples, and honest docs.

## Try one in under a minute

Epoch (MCP) in Claude Code / Cursor-style clients:

```bash
claude mcp add epoch -- npx @puenteworks/epoch
```

Useful feedback: estimated vs actual duration, task context, model/token cost, and where the forecast was wrong.

## How we ship

- **Proof over theater** — installs, tests, examples, honest release notes.
- **Local-first when the data is yours** — media, studio knowledge, private workflows.
- **Tools, not just prompts** — CLIs, MCP servers, typed commands, repeatable paths.
- **Docs are product** — README, topics, package metadata, `llms.txt` where they earn their keep.
- **Respect the domain** — pottery, translation, video, creative code, and ops have real expertise.
