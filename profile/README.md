## Products

| Project | What it’s for |
| --- | --- |
| [Kinocut](https://github.com/KyaniteLabs/kinocut) (formerly mcp-video) | Local video edit/inspect/caption/clip via MCP + CLI (`pip install kinocut`) |
| [DialectOS](https://github.com/KyaniteLabs/DialectOS) | Spanish dialect & product-copy QA (MCP server + CLI via [GitHub Release tarballs](https://github.com/KyaniteLabs/DialectOS/releases)) |
| [Epoch](https://github.com/KyaniteLabs/Epoch) | Time, cost, token, and schedule-risk estimation |
| [Liminal](https://kyanitelabs.github.io/liminal/) | NL → p5 / GLSL / Three.js / music / video workbench (source currently private) |
| [OpenGlaze](https://github.com/KyaniteLabs/openglaze) | Ceramic glaze calculator (UMF, CTE, recipes) |
